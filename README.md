# ; Semicolon Threejs

An interactive 3D Cosmic Glass / Ethereal Dreamscape Three.js experience featuring an abstract Semicolon 3D model.

## Features
- **3D Model**: Centered Semicolon GLTF mesh with PBR shading and floating levitation.
- **Cosmic Glass Crystals**: Procedurally generated floating crystal prisms (octahedrons, icosahedrons, toruses) with glass refraction, transmission, and clearcoat.
- **Dynamic Energy Cores**: Dual orbiting energy orbs (Amethyst & Celestial Gold) casting dynamic point lights across the scene.
- **Nebula Starfield**: 2,000 vertex-colored particle cloud with atmospheric depth fog.
- **Controls**: Interactive OrbitControls with smooth damping (rotate, zoom, pan).

## Tech Stack
- [Three.js](https://threejs.org/) (r186+)
- [Vite](https://vite.dev/)
- Vanilla CSS & HTML5 Canvas

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
